Sobre o Curso

O curso de Desenvolvimento de Software Multiplataforma prepara estudantes para o desenvolvimento de soluções de software destinadas a diferentes plataformas e ambientes tecnológicos.

Neste projeto são apresentadas as disciplinas que compõem o 3º semestre, permitindo navegar entre diferentes áreas estudadas durante o curso.

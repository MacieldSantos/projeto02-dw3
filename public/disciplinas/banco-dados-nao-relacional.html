Sobre a Disciplina

Banco de Dados Não Relacional apresenta conceitos relacionados ao armazenamento e à manipulação de dados utilizando modelos diferentes do modelo relacional tradicional.

Principais Tópicos

  • Conceitos de bancos de dados NoSQL
  • Modelagem de dados não relacional
  • Bancos orientados a documentos
  • Operações de consulta e manipulação de dados
  • Estruturas de documentos e coleções
  • Aplicações de bancos NoSQL

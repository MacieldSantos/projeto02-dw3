Sobre a Disciplina

Técnicas de Programação II trabalha conceitos e técnicas para organização e desenvolvimento de software, incluindo a aplicação de padrões de projeto na solução de problemas de programação.

Principais Tópicos

  • Programação orientada a objetos
  • Padrões de projeto
  • Padrões criacionais
  • Factory Method
  • Builder
  • Organização e reutilização de código
